## 发现及修改

1. 初始两端仍运行 20260912 的旧 UART 后端，无法按新 SPI 接线操作 S017。已替换为 S017 固件。
2. 车载初始化卡在厂家配置偏移 0xE3 的 IRCAL（0x17），原 20 ms 初始化 CTS 限制过短。仅此启动校准命令使用 350 ms 有界等待，并扩大轮询次数上限；普通初始化命令仍 20 ms，运行命令仍 5 ms，500 ms 安全失联阈值未改变。
3. 遥控端调试中曾出现能识别型号但配置读回为零、发射超时的情况。新增初始化配置读回验证：必须读到 `05 38 00 28` 才允许 ready=1，否则 error=8 并 SDN 关断。此异常的全部电气原因尚未单独证明，不能仅凭后续成功断言硬件不存在间歇问题。
4. 增加配置偏移、最后命令、命令阶段、CTS、PH/CHIP pending 和配置读回诊断量。临时发射超时额外查询已撤除，正常发射仍异步运行。
5. SPI 曾临时降低到 250 kHz 对照，未解决当时异常；最终恢复约 1 MHz（分频 64），没有修改接线或射频频点、功率码。

校准耗时依据：[Silicon Labs Si4464/63/61/60 数据手册，Image Rejection and Calibration](https://www.silabs.com/documents/public/data-sheets/Si4464-63-61-60.pdf)，初始校准约 250 ms。350 ms 是本次软件设置的单条校准命令上限，不是制造商保证的所有环境最大值。

主机测试 11/11 通过，其中增加两阶段 150/100 ms 校准模拟和配置读回错误的关断测试。两端 GNU 构建通过；未在本次验证 Keil 构建。

## 后续验证

1. 保持台架隔离，补齐遥控 INA226/按钮检测、车载可 ACK 的 CAN 节点。
2. 在独立假负载上验证 READY、GO 单次脉冲、STOP、失联、复位及 CAN 故障锁存。
3. 进行两端断电冷启动、多次重启、实际安装距离及干扰测试，统计有效包间隔和错误计数。
4. 在确认最终 SDC/EBS 触点拓扑、外部非可编程锁存、射频使用要求及其他软件发布遗留项后，才进入整车验证。不得把本次无线通包视为接入真实车辆执行回路的许可。
