# 遥控端硬件分配与接线说明

校订日期：2026-10-16。适用STM32G0B1CBT6与S017 Si4463，不适用旧E220 UART或F103工程。

## 共同无线接口


S017 与两端 MCU 均采用 SPI1。两端的信号映射相同：

| MCU | S017 | 方向/作用 |
|---|---|---|
| PA4 | 9 nSEL | SPI 片选，低有效 |
| PA5 | 6 SCLK | SPI 时钟 |
| PA6 | 7 SDO | S017 输出，MCU MISO |
| PA7 | 8 SDI | MCU 输出，S017 MOSI |
| PB2 | 5 nIRQ | 低有效状态输出，主循环轮询 |
| PB3 | 10 SDN | 高电平关断，低电平工作 |
| 3.3 V | 1、2 VCC | 两个 VCC 脚都连接 |
| GND | 11、12 GND | 两个 GND 脚都连接 |
| 不接 | 3 GPIO0、4 GPIO1 | 当前驱动不需要 |

杜邦线优化要求：

1. MCU、S017 和本端电源必须共地；两端之间不需要用杜邦线连接地线。
2. VCC 只能接稳定的 3.3 V，不能接 5 V；S017 不能由 MCU GPIO 或 J-Link 信号脚供电。
3. PA4、PA5、PA6、PA7、PB2、PB3 六根信号线尽量短，避免与继电器线圈、DC/DC 输入线和天线馈线并行。
4. SCLK、SDI、SDO、nSEL 使用同一组短线；建议将 GND 线夹在信号线旁边，形成“信号—地”交替排列，减少回路面积。
5. 杜邦线接触不可靠时，优先使用锁紧排线或焊接短线。若必须使用杜邦线，插接后轻拉确认，不要让模块由线束悬空摆动。
6. 当前软件针对杜邦线降低了 SPI 速率至约 250 kHz，降低 PA4/PA5/PA6/PA7 边沿速度，增加 nSEL 建立/保持间隔，并对关键配置进行两次只读回读验证。
7. 这些软件措施不能修复 VCC 压降、GND 断续、SDO/SDI 反接或模块晶振/射频硬件错误。出现 `error=8` 时应先检查供电、接地、片选和读回值，不得旁路安全故障。

Si4463 初始化成功的最低诊断条件为：`part=0x4463`、`ready=1`、`error=0`，关键中断配置读回 `05 38 00 28`。初始化失败时 SDN 拉高，禁止继续发射。


## 4 遥控端接口


| MCU 引脚 | 接口 | 电气定义 |
|---|---|---|
| PB0 | GO 按钮 | 上拉输入；按下接地为低 |
| PB1 | 急停检测 | 常闭链健康为低；按下、断线或检测板掉电为高 |
| PB6 | INA226 SCL | I2C，3.3 V 上拉 |
| PB7 | INA226 SDA | I2C，3.3 V 上拉 |
| PA8 | INA226 ALERT | 可选输入，当前主要使用 I2C 轮询 |
| PB13 | 四灯 IN1 | 红灯，低电平有效 |
| PB12 | 四灯 IN2 | 绿灯，低电平有效 |
| PB11 | 四灯 IN3 | 黄灯，低电平有效 |
| PB10 | 四灯 IN4 | 蓝灯，低电平有效 |

四灯编号采用用户确认的映射：1 红、2 绿、3 黄、4 蓝。继电器触点应使用 NO，不使用 NC；继电器输入必须确认 3.3 V 逻辑兼容。上电约 1 s 四灯自检属于启动检查，不代表无线链路已建立。

INA226 使用 7 位地址 `0x40`，软件标定为 10 mΩ 分流器。当前电压阈值为约 11.1 V 预警、10.5 V 严重低电量；电池和分流器规格变化时必须重新标定。测量模块无效时，遥控端不得获得正常 READY 许可。


## 调试与验收边界

PA13为SWDIO，PA14为SWCLK。IWDG名义约500 ms，实际时间受LSI偏差影响，须实测。灯或继电器命令位不代表物理负载状态。下载、复位、MCU无电与交错上电状态下分别检查实际输出。

VCU独立RES_ERROR健康12 V、故障0 V，先于TSMS建立有效健康状态。EBS主支路24 V，安全回路外部DCDC后12 V。整车硬件锁存保留，不由RES软件恢复清除。完整状态机和未关闭事项见 ../../docs/RES_SYSTEM_DESCRIPTION_CN.md；CAN契约见 ../../docs/VCU_INTEGRATION.md。
