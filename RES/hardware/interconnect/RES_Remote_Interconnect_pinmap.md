# RES 遥控端连接板引脚对照（当前原理图/PCB）

## 正式工作链路

| 功能 | STM32G0B1 载板端 | 中间器件 | E220 载板端 |
|---|---|---|---|
| USART1 发送 | `PA9 / J2-22` | `R1 = 33 Ω` | `RXD / E220 pin 15` |
| USART1 接收 | `PA10 / J3-19` | `R2 = 33 Ω` | `TXD / E220 pin 14` |
| LoRa 从控复位 | `PB5 / J3-9` | `R7、Q1(2N7002)、R5/R6` 开漏级 | `REST / E220 pin 6` |
| 扩展 PA0 | `PA0 / J2-4` | `R10 + D3` | `J8/J9` 对应端子 |
| 扩展 PA1 | `PA1 / J2-5` | `R11 + D4` | `J8/J9` 对应端子 |
| 扩展 PA2 | `PA2 / J2-6` | `R12 + D5` | `J8/J9` 对应端子 |
| 扩展 PA3 | `PA3 / J2-7` | `R13 + D6` | `J8/J9` 对应端子 |

UART 必须交叉：STM32 `TX -> E220 RXD`，E220 `TXD -> STM32 RX`。固件使用 USART1，9600 bit/s、8N1、无硬件流控。

## STM32 模块母座

- `J2`：对应 5 V/PA9 一侧排针；`J3`：对应 3.3 V/PA10/PB5 一侧排针。
- `J2-1/J2-2` 与 `J3-1/J3-2` 的双 GND 位按当前旋转后的实物方向接地。
- 正式信号：`J2-4=PA0`、`J2-5=PA1`、`J2-6=PA2`、`J2-7=PA3`、`J2-22=PA9_TX`、`J3-9=PB5`、`J3-19=PA10_RX`。
- PCB 中 J2/J3 旋转为纵向，模块 USB-C 朝载板 `-Y`；不得仅按屏幕上的上下顺序判断引脚，必须以方形 1 脚焊盘和实物丝印共同确认。

## E220 评估板 19 针定义

| E220 总针号 | 名称 | 连接板处理 |
|---:|---|---|
| 1 | VCC | `+3V3_RADIO` |
| 2、3 | 3.3V | 按原理图分别接受保护 3.3 V 电源域 |
| 4、8 | VIO | `+3V3_MCU/逻辑电源域` |
| 5、17、19 | GND | GND |
| 6 | REST | 开漏复位链路 |
| 7 | SWIM | 仅检修/下载，不与外部 STM32 并接 |
| 9 | PC0/RST | 仅检修测试 |
| 10 | PB7/MISO | 仅检修测试 |
| 11 | PB6/MOSI | 仅检修测试 |
| 12 | PB5/SCLK | 仅检修测试 |
| 13 | PB4/NSS | 仅检修测试 |
| 14 | TXD | 经 R2 到 STM32 PA10/RX |
| 15 | RXD | 经 R1 接 STM32 PA9/TX |
| 16 | M1 | 经 R8 配置/测试 |
| 18 | M0 | 经 R9 配置/测试 |

E220 评估板实物为 `1×7P + 1×8P + 1×2P + 1×2P = 19P`，对应载板 `J4/J5/J6/J7`。PB4…PB7、PC0 属于 E220 板载 STM8 与射频模块之间的内部控制域，不得与外部 STM32 形成双主机争用。

## 装配方向

- LoRa 实物射频端朝载板 `+Y`，Micro-USB 朝 `-Y`。
- STM32 USB-C 朝 `-Y`，位于 LoRa 左侧。
- `J2…J7` 母座装在载板底面，两块模块在载板下方、元件面朝上插接。
- 生产前必须以 1:1 纸样和实物重新确认全部 1 脚方向；当前坐标未通过实物量测前禁止下单。
