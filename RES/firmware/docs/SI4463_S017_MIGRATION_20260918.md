# S017 Si4463 模块迁移说明（RES）

> 后续状态：已完成 S017 软件适配与主机回归测试；本文件以下内容是迁移前分析记录，关于“未做/待确认后再编码”的状态已经过时。当前实现、参数和剩余 HIL 项以 [最终候选版本说明](SI4463_FINAL_SOFTWARE_20260918.md) 为准。

日期：2026-09-18  
适用工程：`RES_Remote_G0B1`、`RES_Vehicle_G0B1`

## 结论

具体的端子、供电、断电检查和上电静态验收步骤见 [`SI4463_S017_HARDWARE_WIRING_MODIFICATION_20260918.md`](SI4463_S017_HARDWARE_WIRING_MODIFICATION_20260918.md)。

S017 不是 E220 一类的 UART 透传模块。根据随附的《S017_ Si4463数传模块说明文档》，它需要 STM32 通过 SPI 发送 Si4463 命令，并使用 `nIRQ`、`nSEL`、`SDN` 等控制信号；模块工作电压为 1.8–3.6 V，RES 系统只能给它提供受控的 3.3 V。

当前两个 STM32 工程的默认无线链路仍是：

```text
PA9  (USART1_TX) -> E220 RXD
PA10 (USART1_RX) <- E220 TXD
```

因此，不能只修改频点、波特率或 USART 初始化，就把 S017 当成现有 E220 替换使用。若实物仍只有 PA9/PA10 两根数据线，S017 无法通过软件兼容；必须提供 SPI 和控制线，或者继续使用 UART 透传模块。

## S017 接口核对

| S017 引脚 | 名称 | 方向/用途 | RES 侧要求 |
|---:|---|---|---|
| 1、2 | VCC | 电源 | 稳压 3.3 V；禁止接 5 V |
| 3 | GPIO0 | 可选 GPIO | 未使用时悬空；若 WDS 配置使用，需分配 MCU GPIO |
| 4 | GPIO1 | 可选 GPIO | 未使用时悬空；若 WDS 配置使用，需分配 MCU GPIO |
| 5 | nIRQ | 模块中断输出，低有效 | MCU EXTI 输入；必须能被 MCU 读取 |
| 6 | SCLK | SPI 时钟输入 | MCU SPI SCK |
| 7 | SDO | SPI 数据输出 | MCU SPI MISO |
| 8 | SDI | SPI 数据输入 | MCU SPI MOSI |
| 9 | nSEL | SPI 片选，低有效 | MCU GPIO 输出 |
| 10 | SDN | 关断控制，高电平关断 | MCU GPIO 输出；初始化保持低 |
| 11、12 | GND | 地 | 与两端 MCU 共地 |

## 候选引脚分配（仅在实物已按此接线时采用）

当前 CubeMX 文件中 PA4–PA7、PB2、PB3 没有被现有 RES 功能占用，可作为两端相同的候选分配：

| STM32 | S017 | 说明 |
|---|---|---|
| PA5 / SPI1_SCK | 6 SCLK | SPI 时钟 |
| PA6 / SPI1_MISO | 7 SDO | 模块到 MCU |
| PA7 / SPI1_MOSI | 8 SDI | MCU 到模块 |
| PA4 | 9 nSEL | 低有效片选 |
| PB2 | 5 nIRQ | EXTI，低有效 |
| PB3 | 10 SDN | 低电平工作，高电平关断 |
| 3.3 V | 1、2 VCC | 必须确认稳压能力和去耦 |
| GND | 11、12 GND | 单点共地优先 |

这是软件候选表，不是对 PCB 走线的推定。遥控端 PB6/PB7 目前已用于 INA226 I²C，不能把它们同时当作 SPI；早期原理图中出现的 PB4–PB7 LoRa 标注与当前 CubeMX/硬件分配不一致，必须以实物飞线或最新原理图为准。

## 必须补齐的软件内容

确认引脚后，两个端点都要同步完成以下修改：

1. 在 CubeMX 中启用 SPI1，并配置 `nSEL`、`nIRQ`、`SDN`；开启 HAL SPI 支持和 EXTI 中断。
2. 新增 Si4463 低层驱动：`POWER_UP`、命令/响应轮询、`GET_INT_STATUS`、TX FIFO、RX FIFO、清中断和复位时序。
3. 导入与模块晶振、目标频点、调制方式、空口速率、频偏、RX 带宽、同步字、CRC 和数据包长度匹配的 WDS 配置数组。不能凭空使用 E220 的 UART 参数替代这些配置。
4. 将 RES 的帧发送/接收适配到 Si4463 FIFO 和 `nIRQ`，保留现有 RES 帧 CRC、认证、ACK、STOP 优先级和 ASF 失效安全逻辑。
5. 物理跳频必须由 Si4463 的频率寄存器真正执行；遥控端和车载端的信道表、晶振频率和校验配置必须完全一致。
6. 上电/复位阶段 `SDN=0`、`nSEL=1`，继电器输出仍按原有失效安全默认值；无线初始化失败时只能进入故障/STOP，禁止吸合启动继电器。

## 当前已做与未做

- 已做：在本文件中记录 S017 的接口事实、3.3 V 限制、候选引脚和迁移边界。
- 保持不变：现有 E220 UART 生产构建、原有 ASF 状态机和当前 HIL 烧录映像。
- 未做：没有把 PA9/PA10 强行改成 SPI，也没有生成未经 WDS 验证的 Si4463 射频寄存器表；这样做会造成“能编译但无法收发”甚至硬件冲突。

## 继续修改前必须确认

请提供两端“STM32 引脚 ↔ S017 引脚”的实物照片或表格，至少确认 `SCLK/SDO/SDI/nSEL/nIRQ/SDN/VCC/GND` 八项；同时确认模块晶振频率和目标空口参数。确认后再修改两个 `.ioc`、加入驱动和配置数组，编译生成两端 HEX，并先做无继电器台架收发测试。
