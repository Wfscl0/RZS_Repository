# RES 硬件在环（HIL）测试总说明与检查表

> 版本：2026-09-03；适用对象：遥控端 STM32G0B1、车载端 STM32G0B1、两块 E220 STM8 无线桥、CAN 分析仪/仿真器和 VCU HIL 台架。  
> 本文件是台架测试计划，不是赛事合规结论，也不能替代断电、机械急停和独立硬件锁存验证。

## 1. 使用边界和通过规则

开始 HIL 前，两个继电器触点必须与真实车辆高压/低压安全回路隔离，或接入经过评审的等效负载与测量夹具。台架中所有可能使继电器吸合、START_OUT 翻转或 VCU 改变状态的试验，都必须保留人工硬件急停和独立断电手段。

每一项检查记录日期、操作者、硬件版本、两个 STM32 映像的 SHA-256、VCU 软件版本、CAN 日志文件名及结果。任何一项安全预期未满足时，停止后续扩大测试，保持两个继电器释放并记录故障；不得以软件重启替代硬件锁存器的人工复位或 LVMS 断电流程。

测试通过的最低条件是：

- 所有“必须”项均有可复现记录；
- 从故障、丢链、CAN 超时、复位和非法帧进入安全状态的动作均被测量验证；
- 未出现“锁存故障而任一继电器仍闭合”或“无新 GO 事件却出现 VCU 启动请求”的组合；
- 未将公开演示密钥、完整现场密钥或私密串口/CAN 日志提交到仓库或测试报告。

## 2. 当前接口基线

### 2.1 时间与总线

| 项目 | 当前约定 | HIL 判据 |
|---|---|---|
| 车载端到 VCU CAN | 11 位标准帧、Classic CAN、500 kbit/s、DLC=8 | CAN 工具按该配置捕获，帧不得被当作 CAN-FD 或扩展 ID |
| `0x510 RES_STATUS` | 周期 50 ms | 正常工作时连续捕获；VCU 超过 150 ms 未收到**完整且语义合法**的状态帧即进入 `RES_ERROR` |
| `0x511 RES_GO_EVENT` | 每个经认证的新 GO 操作一次 | VCU 仅在状态新鲜且 READY、全部自身安全条件满足时接受新的 `(remote_session, command_counter)` |
| `0x512 RES_DIAGNOSTIC` | 与接受的 GO 事件伴随 | 只用于追溯/交叉检查，单独出现绝不能产生 GO |
| 无线有效链路超时 | 车载端约 500 ms | 最后一帧有效认证无线帧后约 500 ms，两个继电器均释放并锁存故障 |
| START_OUT | 约 100 ms 脉冲 | 只作为冗余指示；不得绕过 VCU 的 CAN 和独立安全条件 |
| IWDG | 两端名义约 1 s | 复位测试中输出必须先进入安全电平 |

`0x510` 字节定义由 `../shared/include/res_can_contract.h` 和
`../dbc/RES_CAN_Validation.dbc` 共同给出：

| 字节 | 内容 | 合法/安全判定 |
|---:|---|---|
| 0 | 协议版本 | 固件当前为 `0x01` |
| 1 | 状态 | `0=BOOT, 1=WAIT_LINK, 2=READY, 3=GO_EVENT, 4=STOPPED_FAULT` |
| 2..3 | 小端 flags | bit0 为 LINK_OK；bit1..7 任一置位为安全故障/恢复中语义；高字节保留，必须为 0 |
| 4 | 射频信道索引 | 当前实现 0、1、2 |
| 5 | bit0/bit1：继电器 1/2 逻辑闭合命令 | READY/有效 GO 时应为 `0x03`；bit2..7 必须为 0；这不是机械触点反馈 |
| 6..7 | 小端 GO 事件计数器 | 仅用于状态追溯，不能替代 `0x511` 的去重键 |

2026-10-04 上电接口修订：不再等待 EBS/RES 两路都输出 1 才开始监测；TSMS 上电前先给 `RES_ERROR` 12 V 健康电平，故障为 0 V。EBS 安全回路经 DCDC 降为 12 V。本文的旧无线硬件基线仍按其原版本保留。

**不要混淆三个输出：**车载 `PB12 START_OUT`、车载 `PB13 FAULT_OUT` 和由 VCU 驱动的独立 `RES_ERROR` 不是同一信号。`RES_ERROR` 按正常 12 V、故障 0 V 实测，不能从车载端 `FAULT_OUT` 的有效高配置推断。

### 2.2 关键硬件前提

- 两端 MCU 都是 STM32G0B1CBT6，时钟目标 64 MHz；UART1 为 9600-8-N-1。
- 遥控端：PB0 为低有效 GO 输入，PB1 为高有效 STOP/断线故障输入；PB6/PB7 连接 INA226，PA9/PA10 连接 E220 UART。详见遥控端硬件分配说明。
- 车载端：PB10/PB11 驱动两个低有效继电器模块，PB12 为 START_OUT，PB13 为 FAULT_OUT，PB8/PB9 为 FDCAN1 RX/TX，PA0 为 CAN 收发器 STB。详见车载端硬件分配说明。
- 低有效继电器模块必须在 PB10/PB11 外加 4.7–10 kΩ 上拉，且须在复位、掉电、下载、调试器接入时实际测得“释放”。不同批次模块的电平可能不同，不能只相信丝印或代码宏。
- CAN 总线仅在物理两端使用 120 Ω 终端；接入 CAN 分析仪时确认它没有额外使总线过度终端。CAN 收发器、电源和地必须按实际硬件共模范围连接。
- E220 仅以相同的桥接固件、相同三频点表和相同 air-rate index 工作。桥接 STM8 不拥有认证密钥，不能作为授权 GO 的依据。

- 不在本文、Keil 工程、截图、串口日志、CAN 日志或提交记录中写入密钥；
- HIL 记录只保存双方匹配的密钥指纹（例如经团队批准的 SHA-256 截断值），不保存原文；

## 4. CAN 注入与观测向量

下表为 CAN 工具可直接使用的十六进制载荷。所有帧均为标准 ID、DLC=8、500 kbit/s。带“期望”项的向量用于验证 VCU 接口和故障处理；它们不是要求车载端必须人工构造的正常运行帧。

| 编号 | CAN ID | 数据（Byte0 → Byte7） | 预期 |
|---|---:|---|---|
| CAN-01 | `0x510` | `01 02 01 00 00 03 34 12` | 合法 READY：LINK_OK、两个继电器逻辑闭合、GO 计数 `0x1234`；VCU 可解除由状态缺失导致的 `RES_ERROR`，但不自动 GO |
| CAN-02 | `0x510` | `01 03 01 00 01 03 35 12` | 合法 GO_EVENT 状态快照；仍不能单独生成 GO |
| CAN-03 | `0x510` | `01 04 82 00 00 00 35 12` | REMOTE_STOP + SOFTWARE_LATCHED；VCU 必须安全故障 |
| CAN-04 | `0x510` | `01 04 84 00 00 00 35 12` | RADIO_TIMEOUT + SOFTWARE_LATCHED；VCU 必须安全故障 |
| CAN-05 | `0x510` | `01 01 00 00 00 01 00 00` | WAIT_LINK，继电器 1 仅闭合；VCU 必须保持/进入安全故障 |
| CAN-06 | `0x511` | `44 33 22 11 DD CC BB AA` | GO 键为 session=`0x11223344`，counter=`0xAABBCCDD`；仅在新鲜 CAN-01 与 VCU 全部独立条件成立时产生一次内部 GO 脉冲 |
| CAN-07 | `0x512` | `DD CC BB AA 35 12 01 01` | 对 CAN-06 的诊断副本（event=`0x1235`、channel=1）；不得产生 GO |

下面非法/故障输入分别注入，并确认它们不刷新“最后有效状态”时间戳：

| 编号 | CAN ID | 数据 | 期望 |
|---|---:|---|---|
| CAN-F01 | `0x510` | `02 02 01 00 00 03 34 12` | 版本不匹配，`RES_ERROR` 保持/置位 |
| CAN-F02 | `0x510` | `01 05 01 00 00 03 34 12` | 非法状态，`RES_ERROR` 保持/置位 |
| CAN-F03 | `0x510` | `01 02 01 01 00 03 34 12` | flags 高字节保留位非零，协议故障 |
| CAN-F04 | `0x510` | `01 02 01 00 00 07 34 12` | 继电器保留位非零，协议故障 |
| CAN-F05 | `0x510` | `01 02 01 00 03 03 34 12` | 未实现的信道索引，协议故障 |
| CAN-F06 | `0x510` | `01 02 09 00 00 03 34 12` | AUTH_FAILURE 置位，安全故障 |
| CAN-F07 | `0x510` | `01 02 21 00 00 03 34 12` | SESSION_RECOVERY 置位，即使 LINK_OK 也不得视为 READY |

## 5. HIL 执行清单

### A. 不接入车辆安全回路的上电与烧录检查

- [ ] 断开真实 SDC/动力系统，使用假负载或继电器状态测量夹具；确认人工急停和独立电源开关有效。
- [ ] 确认 J-Link SWDIO、SWCLK、NRST 和 GND 接线正确；两端分别擦除/烧录指定映像并完成读回或校验。
- [ ] 在 MCU 未上电、NRST 低、下载中、IWDG 复位及掉电五种状态下测 PB10/PB11 及两个继电器触点；两触点均应处于释放状态。
- [ ] 车载端通电而遥控端未通电：测得 R1 逻辑闭合、R2 逻辑释放，`FAULT_OUT` 处于本板故障有效状态；记录实测电压，不用逻辑名称代替读数。
- [ ] 遥控端 PB1 在“健康、按下急停、断开检测线、检测模块掉电”四种情况分别测量；后 3 种都必须被软件识别为 STOP/故障。
- [ ] 检查 INA226 地址、分流电阻和电池电压读数；电量采样异常在启动宽限后应禁止运行并进入安全状态。

### B. 认证无线链路、状态机和继电器

- [ ] 使用相同的受控本地密钥和相同 STM8 频点表；上电后捕获 HELLO/ACK/READY 过程。新会话收到 3 帧有效 READY 后，车载端两个继电器才可逻辑闭合。
- [ ] 按一次 GO：确认车载端仅出现一个 100 ms START_OUT 脉冲、一个 `0x511` 和一个伴随 `0x512`；不应因持续按键/重复帧多次计数。
- [ ] 在 READY 中按 STOP：记录从输入动作到两个继电器触点释放的时间；CAN 应转为 `STOPPED_FAULT`，含 `REMOTE_STOP` 与 `SOFTWARE_LATCHED`。
- [ ] STOP 锁存后，在同一无线会话内持续发送 READY；两个继电器均不得再次闭合。
- [ ] 释放急停并重启遥控端形成新认证会话；验证经过 3 个有效 READY 后才允许车载端恢复。
- [ ] 断开天线、断开任一 E220 电源或屏蔽链路；记录从最后有效无线帧到 500 ms 超时、安全锁存和继电器释放的时间。
- [ ] 单独阻断每个跳频信道，再阻断两个信道；记录桥接扫描/重获过程。不得用“逻辑信道字段变化”代替实际射频换频证据。

### C. CAN 与 VCU 监督

- [ ] CAN 分析仪导入 `../dbc/RES_CAN_Validation.dbc`，确认 `0x510` 平均周期约 50 ms、标准 ID、DLC=8。
- [ ] 持续发送 CAN-01；在 VCU 的 AS Ready 以外状态下确认没有 GO，仅 `RES_ERROR` 的状态监督可由合法帧恢复。
- [ ] 在 CAN-01 新鲜、VCU 的所有独立前提满足时发送 CAN-06；确认 VCU 只产生一次 GO 脉冲/请求。原样重复 CAN-06，重复帧不得再次 GO。
- [ ] 在 CAN-01 过期、CAN-F01..CAN-F07 任一生效、VCU 不处于 AS Ready 或已有安全故障时发送 CAN-06；均不得 GO。
- [ ] 只发送 CAN-07，或只使 `0x510` 的 GO 计数递增；均不得 GO。
- [ ] 停止合法 `0x510`，在最后一帧后分别测 149 ms、150 ms、151 ms 的 VCU 状态；规格是 **大于 150 ms** 未收到合法状态即主动 `RES_ERROR`。记录任务周期带来的测量分辨率。
- [ ] 注入 CAN-F01..CAN-F07、错误 DLC、扩展 ID、解码器故障、CAN 收发器掉电和 FDCAN bus-off；VCU 必须故障安全，且非法状态不得延后 150 ms 超时。
- [ ] 冷启动 VCU、重启 CAN 接收任务或制造任务超时；物理 `RES_ERROR` 必须先进入故障有效状态，再等待合法新鲜 READY。随后验证 RES_ERROR 建立 12 V 后才上电 TSMS；不增加双路健康等待使能。确认实际故障锁存的复位与通信恢复相互独立。
- [ ] 测量 EBS 安全回路 DCDC 输出及 SDC_IN 为 12 V，分别检查安全回路断开和主电源掉电；EBS_PWR 主电源仍按 24 V 测量。

### D. 证据与退出条件

- [ ] 保存至少一段包含 READY、GO、STOP、无线丢链、CAN 150 ms 超时和非法帧的原始 CAN 日志；日志中不含密钥。
- [ ] 保存继电器触点、PB10/PB11、START_OUT、FAULT_OUT、VCU `RES_ERROR` 的示波器/逻辑分析仪截图，并标记触发基准和刻度。
- [ ] 在测试记录中注明：继电器“命令位”与真实触点测量结果是否一致；若没有接触点反馈硬件，不得把 DBC 的 relay bit 宣称为物理反馈。
- [ ] 任何场地/距离、EIRP、占空比与干扰环境测试均单列报告；通过本台架检查表不等于无线法规或赛事规则合规。
