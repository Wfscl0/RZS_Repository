# VCU全程序检查与修改记录（2026-07-28）

## 1. 检查范围与边界

本次检查覆盖：`Sources`主入口、`Generated_Code`底层配置、`ImpCode`手写驱动/OS/接口、`VCU10_ert_rtw`模型生成代码、`Models/DBC_Debug/VCU10.slx`及数据字典、CAN调试DBC。

保持条件：

- 不改变现有“中断/驱动 → FreeRTOS队列 → CoreApp → Simulink → VcuCtrl/CanOut”架构。
- 接插件功能以车辆电气拓扑原理图为准。
- 轮速传感器暂不使用，模型物理输入固定为0；调试字段只保留接口。
- TLF35584内部硬件看门狗暂不启用。
- 安全策略采用延时确认和恢复确认，避免单帧抖动误触发。
- ADC传感器最终标定仍待实车/台架测量，本次只设置合理占位值和正确量纲。

## 2. 当前软件数据流

```text
main
  └─ OS_All_Init
      ├─ 建立初始化任务
      └─ 初始化任务先创建队列，再启动可产生中断的外设

ADC/ADS1115/GPIO/CAN/UART
  └─ ISR或采集任务写队列
      └─ CoreApp每10 ms读取、做新鲜度处理、填写模型根输入
          └─ VCU10_step（基础步长10 ms）
              ├─ CanOut按10/20/50/100/500 ms发送
              └─ VcuCtrl每10 ms更新输出，200 ms执行低速维护
```

## 3. 原理图接口映射

### 3.1 模拟量

| 模型量 | 底板接口 | 手写输入 | 换算 |
|---|---|---|---|
| APP1 | AIN0，0～5 V | ADS1115 CH0 | 187.5 µV/count |
| APP2 | AIN1，0～5 V | ADS1115 CH1 | 187.5 µV/count |
| 制动踏板 | AIN2，0～5 V | ADS1115 CH2 | 187.5 µV/count |
| 气压1 | AIN4，0～10 V | MCU ADC结果0 | 2.416992 mV/count，0～10 V→0～1 MPa |
| 气压2 | AIN5，0～10 V | MCU ADC结果1 | 同上 |
| 四轮油压 | CAN1 ESP_T_03 | CAN报文 | 不使用ADC |

当前踏板占位标定为0.252 V对应0、2.000 V对应1。气压模型内部采用bar，0～10 V对应0～10 bar，即0～1 MPa。

### 3.2 数字输入

| HIN位 | 原理图功能 |
|---:|---|
| 0 | EBS Check |
| 1 | Shutdown Start |
| 2 | Shutdown End |
| 3 | 舱外 DI8 |
| 4 | 舱内 DI8 |
| 5 | Run |
| 6 | TSMS |
| 7 | ASMS |

CoreApp直接每10 ms读取HIN，避免辅助传感器慢任务拖慢关键开关量。

### 3.3 输出

| 模型输出位 | 原理图功能 |
|---|---|
| LOX bit0～6 | ASSI蓝、ASSI黄、制动灯、Emergency蜂鸣器、R2D蜂鸣器、EBS故障灯、DI8 |
| HOX bit0～3 | Run、BMS灯、IMD灯、EBS Trigger |
| ebs_watchdog | PA30使能 | ASMS=0时0%占空比，ASMS=1时10 kHz/50% |

RES错误保留为模型内部诊断，原理图没有独立物理输出，因此在模型中明确接至Terminator。

## 4. 已完成修改

### 4.1 模型

- 根输入/输出名称、数量和顺序保持不变。
- 修正踏板、制动踏板和两路气压的ADC增益、饱和范围及信号来源。
- Stateflow本地状态增加显式初值。
- RES心跳容错提高到约300 ms；Stop增加当前帧XOR和通信有效联合门控。
- AS Emergency在同一模型周期把电机需求扭矩强制为0。
- 输出打包按2026-07-30网表与引脚表重新排列：OUT1～5为制动、ASSI蓝、ASSI黄、EBS错误、RES错误；HO1～7为EBS触发、BMS、IMD、DI8、RUN、R2D、Emergency。
- 调试覆盖仍为500 ms独立回退，便于TSMaster台架调试。

### 4.2 CAN与接口

- CAN0保持电机专用，CAN1用于ESP/EPS/RES/IPC/AMI和调试帧。
- CAN接收回调仅处理完成的邮箱并只重挂对应接收邮箱，TX完成不再误重挂RX。
- 标准帧要求DLC=8；RES在进入模型前检查Byte2=Byte0 XOR Byte1。
- 生产报文增加接收计数和300 ms新鲜度清零；一般报文需3个有效新帧恢复，RES合法Stop不延迟。
- 发送消息结构清零并使用2 ms有界阻塞发送，避免未初始化字段及覆盖在途邮箱。
- `CAN_Node.h`已实际被CAN驱动和CoreApp包含，生产计数与调试接口均集中在此定义。

### 4.3 底层和任务

- 初始化顺序改为先建队列/事件组，再开启CAN、ADC、UART等中断源。
- CoreApp、VcuCtrl使用10 ms周期；慢速维护保持200 ms，不拆分或改变任务架构。
- 修正GPIO清位表达式、MC33879 16位SPI命令截断、SPI/I2C无界等待和ADS1115寄存器指针错误。
- JY60接收改为有界33字节批次、4快照缓冲；解析增加长度检查、逐帧校验和清零及正确的int16符号换算。
- FreeRTOS线程本地存储指针配置只保留一个定义。
- 模型根输出`ebs_watchdog`已接到接插件PA30（内部PTA31/FTM5_CH6）：ASMS关闭时0%，ASMS开启时按既有10 kHz配置输出50%；TLF35584内部WDI保持关闭。
- 手写C/H文件统一为UTF-8，并把S32DS项目编码设为UTF-8，解决中文注释乱码。

## 6. 仍需台架确认

1. 所有ADC零点、满量程、供电偏差、线束压降和传感器合理性范围；当前标定仅为占位。
2. 外部EBS WatchDog所需PWM频率/占空比。当前在ASMS开启时为10 kHz、50%，若EBS协议要求其他频率必须按其手册修改。
3. OUT/HO实际高低有效极性以及灯、蜂鸣器、EBS Trigger的通电实测。
4. ESP、EPS、RES、IPC和电机控制器在真实总线上的周期、计数器、校验和故障恢复。
5. Emergency会在同一模型周期关闭TS并清扭矩；首次测试仍必须断开高压或CAN0执行器。

SDK/lwIP自身仍有若干编译器告警；未启用网口，本次不修改第三方SDK源码。S32DS无Green Hills插件时会在批处理退出阶段报告GHS工具链清单告警，但GCC编译和产物生成成功。
