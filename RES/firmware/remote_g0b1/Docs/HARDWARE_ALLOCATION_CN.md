# 遥控端硬件分配与 HIL 接线说明

适用工程：`RES_Remote_G0B1`；MCU：STM32G0B1CBT6，LQFP48，3.3 V 逻辑。

> **当前版本（2026-09-18）**：默认固件已经改为 S017 Si4463。无线接线以 [S017 接线说明](../../docs/SI4463_S017_HARDWARE_WIRING_MODIFICATION_20260918.md) 为准：PA4=nSEL、PA5=SCLK、PA6=SDO、PA7=SDI、PB2=nIRQ、PB3=SDN。下文 E220/PA9/PA10 仅为旧版资料，不能用于 S017。IWDG 当前 reload=499，名义约 500 ms，实际时延需实测。软件说明见 [最终候选版本](../../docs/SI4463_FINAL_SOFTWARE_20260918.md)。

## 引脚与默认状态

| 功能 | STM32 引脚 | CubeMX 配置 | 软件逻辑/上电安全状态 | HIL 接线要点 |
|---|---|---|---|---|
| SWDIO | PA13 | Serial Wire | 调试 | 接 SWD/J-Link 的 SWDIO |
| SWCLK/BOOT0 | PA14 | Serial Wire | 调试 | 接 SWCLK；不要在烧录前随意改 Option Bytes |
| E220 UART TX | PA9 | USART1 TX，9600-8-N-1 | 3.3 V UART | 接 E220 `RXD` |
| E220 UART RX | PA10 | USART1 RX，9600-8-N-1，IRQ | 空闲高 | 接 E220 `TXD` |
| INA226 ALERT | PA8 | GPIO 输入、上拉 | 当前版本保留，电量由轮询读取 | 可接 INA226 ALERT；未作阈值中断依据 |
| GO 按钮 | PB0 | GPIO 输入、上拉 | 低有效，25 ms 防抖 | NO 按钮按下接 GND |
| STOP/断线检测 | PB1 | GPIO 输入、上拉 | 高有效；高电平代表按下急停、断线或检测链掉电 | NC/失效安全检测链在健康时必须拉低 |
| INA226 SCL | PB6 | I2C1 SCL，100 kHz | 开漏 | 至少一侧提供 4.7 kΩ 上拉至 3.3 V |
| INA226 SDA | PB7 | I2C1 SDA，100 kHz | 开漏 | 与 SCL 共地；默认地址 `0x40` |
| 蓝色状态灯 | PB10 | 推挽输出 | 当前板级配置低有效；上电初始释放 | 继电器/LED 板批次不同必须实测 |
| 黄色状态灯 | PB11 | 推挽输出 | 当前板级配置低有效；上电初始释放 | 同上 |
| 绿色电量灯 | PB12 | 推挽输出 | 当前板级配置低有效；上电初始释放 | 同上 |
| 红色电量灯 | PB13 | 推挽输出 | 当前板级配置低有效；上电初始释放 | 同上 |

时钟为 HSI16 → PLL（/1 ×8 /2）= 64 MHz；IWDG 为 LSI `/32`、reload 999，名义约 1 s。调试器接入、MCU 复位和下载期间四路灯的安全定义为“继电器板不动作/灯不作为安全执行器”，不能把灯的电平当作继电器安全状态证明。

## 外部模块连接

### E220-400MBL-01

```text
STM32 PA9  (USART1_TX) --> E220 RXD
STM32 PA10 (USART1_RX) <-- E220 TXD
STM32 3.3 V              --> E220 VIO
STM32 GND                --- E220 GND
```

UART 必须交叉连接；E220 的 USB/CH340 与 STM32 不可同时强驱动同一 UART。STM32 不驱动 E220 板载 STM8 与 LLCC68 之间的控制线（PC0、PB4..PB7）；它们应保持未连接或模拟高阻。两块 E220 的 STM8 桥接映像、频点表与 air-rate 配置必须匹配。当前协议包含三信道索引，但“物理跳频”仍需用烧录后的桥接板实测。

### INA226

软件按 INA226 地址 `0x40`、10 mΩ 分流电阻和 500 µA/bit 电流 LSB 标定。实物若不是 R010 分流电阻，必须在 `ina226.c` 与本表中同步修改后再测量电池阈值。采样失败被视为电量无效；在启动宽限结束后该状态会阻止正常运行。

2026-09-11 修订增加 TI 型号 ID、配置/校准回读、转换就绪与溢出检查。读数为 0 V 仍按严重低电量处理，不伪造正常电压；非 INA226 或不兼容模块会明确报告型号错误。新增只读观察量 `res_power_last_error`、`res_power_voltage_mv`、`res_power_last_good_ms`、`res_power_error_count`。`res_led_command_bits` 的 bit0~3 依次表示蓝、黄、绿、红的点亮命令，不代表外灯已被测得亮起。

## 上电与 HIL 前测量

1. 断开所有与真实车辆安全回路有关的线束；遥控端测试只接 3.3 V、E220、INA226 与指示器假负载。
2. 先测 PB0 未按下为高、按下为低；再分别测 PB1 健康为低、按下/断线为高。
3. 测 PB10..PB13 在复位和初始化结束后均为“板级释放”电平。当前宏 `RES_OUTPUT_ACTIVE_LOW=1`，但这是可配置假设，不是实物验收结论。
4. 用示波器或逻辑分析仪确认 PA9/PA10 为 9600-8-N-1，且无 CH340 串口争用。
5. 记录供电电压、INA226 读数与映像 SHA-256；不在记录中写入认证密钥。

## 硬件边界

- GO 和 STOP 输入只表达遥控器操作/检测状态，不能直接接入车辆安全回路。
- 该端没有 CAN、继电器或 `RES_ERROR` 输出；车载端与 VCU 才构成后续安全链路。
- 电量阈值、继电器板有效电平、无线频点与天线/EIRP 都必须按实物和赛场规定复核，不能由本引脚表推定。
