# S017 Si4463 无线模块硬件连接修改说明

版本：V2.0（与 S017 最终候选软件同步）
日期：2026-09-18  
适用端：`RES_Remote_G0B1` 遥控端、`RES_Vehicle_G0B1` 车载端

> 软件已采用下表引脚。用户确认当前尚未接线；请按表连接并逐根测通断。完整的软件变更和待验收项目见 [最终候选版本说明](SI4463_FINAL_SOFTWARE_20260918.md)。

## 1. 改线结论

原 RES 无线接口按 E220 UART 透传设计：

```text
STM32 PA9  (USART1_TX) -> E220 RXD
STM32 PA10 (USART1_RX) <- E220 TXD
```

S017 Si4463 没有 E220 形式的 UART 透传接口，必须改为 SPI 加控制线：

```text
STM32 SPI1 + nSEL + nIRQ + SDN <-> S017 Si4463
```

因此不能只把 E220 拔下、把 S017 的某两个针脚接到 PA9/PA10，然后通过改波特率解决通信问题。

## 2. S017 模块针脚

| S017 针脚 | 标识 | 电气方向/作用 | 接线要求 |
|---:|---|---|---|
| 1 | VCC | 模块电源 | 接受控 3.3 V |
| 2 | VCC | 模块电源 | 与 1 脚同接 3.3 V |
| 3 | GPIO0 | 可选 GPIO | 暂不使用时悬空，不要接 5 V |
| 4 | GPIO1 | 可选 GPIO | 暂不使用时悬空，不要接 5 V |
| 5 | nIRQ | 模块中断输出，低有效 | 接 PB2 输入，由主循环轮询 |
| 6 | SCLK | SPI 时钟输入 | 接 MCU SPI SCK |
| 7 | SDO | SPI 数据输出 | 接 MCU SPI MISO |
| 8 | SDI | SPI 数据输入 | 接 MCU SPI MOSI |
| 9 | nSEL | SPI 片选，低有效 | 接 MCU GPIO 输出 |
| 10 | SDN | 关断控制，高电平关断 | 接 MCU GPIO 输出，正常工作保持低 |
| 11 | GND | 地 | 接系统 GND |
| 12 | GND | 地 | 接系统 GND |

S017 的 VCC 允许范围为 1.8–3.6 V，RES 侧统一使用 3.3 V。禁止将 VCC 接到 5 V、12 V 或 USB 的 5 V 线。

## 3. 推荐的两端统一接线表

以下分配避开了当前工程已占用的主要功能：

| STM32 引脚 | CubeMX 功能 | S017 针脚 | 说明 |
|---|---|---:|---|
| PA5 | SPI1_SCK | 6 SCLK | MCU 输出时钟 |
| PA6 | SPI1_MISO | 7 SDO | S017 输出、MCU 读取 |
| PA7 | SPI1_MOSI | 8 SDI | MCU 输出、S017 读取 |
| PA4 | GPIO 推挽 | 9 nSEL | 低有效片选；空闲必须为高 |
| PB2 | GPIO 上拉输入 | 5 nIRQ | 低有效中断，由主循环轮询；空闲通常为高 |
| PB3 | GPIO 推挽 | 10 SDN | 低电平工作，高电平关断 |
| 3V3 | 电源 | 1、2 VCC | 两个 VCC 都连接 |
| GND | 电源地 | 11、12 GND | 两个 GND 都连接 |

GPIO0、GPIO1 暂不接。若后续 WDS 射频配置要求使用这两个引脚，必须重新分配并在软件中同步配置。

### 3.1 遥控端的特别注意事项

遥控端当前使用：

```text
PB6/PB7 -> INA226 I²C SCL/SDA
PA8     -> INA226 ALERT
PB10~PB13 -> 四色灯
PB0/PB1 -> GO、STOP 输入
```

所以遥控端不能把 PB6/PB7 再并接为 SPI。推荐使用上表的 PA4–PA7、PB2、PB3。

### 3.2 车载端的特别注意事项

车载端当前使用：

```text
PA0     -> CAN 收发器待机控制
PB8/PB9 -> CAN RX/TX
PB10/PB11 -> 继电器 1/2
PB12    -> START_OUT
PB13    -> FAULT_OUT
```

因此推荐候选引脚同样使用 PA4–PA7、PB2、PB3，不得占用 PA0、PB8/PB9 或 PB10~PB13。

## 4. 电源和布线要求

1. S017 的 1、2 脚同时接 3.3 V，11、12 脚同时接 GND。
2. 模块 VCC 旁边放置 0.1 µF 陶瓷去耦；建议再放置 4.7–10 µF 的储能电容。电容应靠近 S017 供电脚。
3. S017、STM32、调试器和其他接口必须共地；SPI 线尽量短，SCLK 远离继电器线圈和高压/大电流线束。
4. nSEL、SDN 在 MCU 复位、下载和未初始化期间不能悬空。建议两者各使用约 10 kΩ 上拉至 3.3 V，使默认状态为 `nSEL=1`、`SDN=1`（关断）。驱动执行复位后才将 SDN 拉低；检测到驱动故障时重新拉高。
5. nIRQ 需要保持可读，不能接到会被 USB-UART 或其他外设强驱动的线上。
6. 不要同时把 S017 的 SPI 线和 USB 转串口模块并接到 PA9/PA10；旧 E220 的 TXD/RXD 线应拆除或保持独立。
7. 若使用排针转接，先确认模块丝印方向。S017 的针脚编号必须按模块说明书核对，不能按颜色线序猜测。

## 5. 断电接线检查

在任何模块上电前完成以下检查：

| 检查项 | 预期结果 |
|---|---|
| VCC 与 GND 电阻 | 不应为近似短路；若很低，停止上电并检查方向 |
| VCC 到 MCU 5 V | 不应导通 |
| SCLK/SDO/SDI | 分别只连到对应 SPI 引脚，无交叉短路 |
| nSEL | 只连接 PA4，不与 nIRQ/SDN 短接 |
| nIRQ | 只连接 PB2，不能接 5 V |
| SDN | 只连接 PB3，确认没有反接到 nIRQ |
| 两端 GND | 低阻连通 |
| 继电器线 | Si4463 改线不应改变继电器驱动线，继电器仍保持原低电平触发设计 |

## 6. 上电后的静态电平验收

未运行 Si4463 驱动、仅给 STM32 和 S017 供电时，建议使用万用表测量：

| 信号 | 预期静态状态 |
|---|---|
| VCC | 3.3 V，不能超过 3.6 V |
| nSEL | 高电平 |
| SDN | 初始化成功时低；复位、未初始化或驱动故障时高（关断） |
| nIRQ | 通常为高电平；若持续低，先检查模块上电/清中断状态 |
| PA9/PA10 | 不再作为 S017 无线数据线 |

静态电平正确不等于无线参数正确；Si4463 仍需要匹配的 `POWER_UP`、频率、调制、速率、同步字、CRC、FIFO 和中断配置。

## 7. 不能采用的连接

- S017 VCC 接 5 V、12 V 或继电器模块电源。
- 只接 VCC、GND、TX、RX，期待 S017 像 E220 一样自动透传。
- 遥控端把 PB6/PB7 同时接 INA226 和 SPI。
- 把 SDO、SDI 反接，或将 nIRQ 当作串口 RX。
- nSEL、SDN 悬空。
- 在继电器已接入车辆安全回路的情况下首次验证无线驱动。

## 8. 与软件修改的对应关系

软件已实现以下路径，硬件接线后仍须验证：

1. 两端 CubeMX 启用 SPI1，生成 PA4–PA7、PB2、PB3 的初始化代码。
2. 增加 Si4463 SPI 命令、状态、FIFO 和 nIRQ 驱动。
3. 已导入用户提供的 WDS 配置数组（30 MHz 配置参数）；实物晶振仍须核对。
4. 将 RES 帧从现有 UART 传输后端切换到 Si4463 FIFO 后端。
5. 保留 STOP 优先、通信超时释放继电器、ASF 心跳停止和认证/CRC 校验逻辑。
6. 在无继电器触点、无 START_OUT 的台架上先验证两端收发，再进行 HIL。
