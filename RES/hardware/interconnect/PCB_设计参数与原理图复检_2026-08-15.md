# STM32G0B1CBT6—E220-400MBL-01 顶置连接板

结论：当前原理图网络尚不能直接转 PCB。必须先修正 UART、LoRa 复位、PTC 封装，并确认 STM32 模块两组 2×12 排针的实际焊盘编号。其余电源滤波、四路外部 IO 防护、M0/M1 默认下拉和 E220 分组连接思路合理。

## 1. 原理图必须修改的项目

### 1.1 UART 两条链路当前断开

当前网表中下列四个网络均只有一个引脚：

- `MCU_TX_PA9`：仅 H1.3；
- `LORA_RXD`：仅 U6.9；
- `LORA_TXD`：仅 U6.8；
- `MCU_RX_PA10`：仅 H2.6。

增加两只 33 Ω、0603 串联电阻：

- `MCU_TX_PA9 — R21 33R — LORA_RXD`；
- `LORA_TXD — R22 33R — MCU_RX_PA10`。

R21靠近 STM32 的 TX 引脚，R22靠近 E220 的 TXD 引脚放置。UART 不需要等长。

### 1.2 LoRa 复位网络当前断开

当前：

- Q2.3 与 R18.1 位于匿名网络 `$1N282`；
- U5.2 单独位于 `LORA_RESET_N`。

应合并为：

`LORA_RESET_N = Q2.3 + R18.1 + U5.2`

栅极网络建议改名：

`RESET_GATE = Q2.1 + R16.2 + R17.2`

其余关系保持：R16=33 Ω，R17=100 kΩ下拉，R18=10 kΩ上拉至 `+3V3_RADIO`，Q2=2N7002，Q2.2接地。

### 1.3 F3、F4 封装错误

网表把 F3/F4 导出为 `R0603`，不能用于 1206L050/15YR。修改为专用 1206 PPTC 封装：

- 型号：Littelfuse `1206L050/15YR`；
- 保持电流：0.5 A；
- 动作电流：1 A；
- 最大工作电压：15 V；
- 封装：1206 / 3216 metric，推荐使用器件官方焊盘，不得沿用 0603 电阻焊盘。

同时把匿名网络改名：

- `$1N232` → `+5V_FUSED`；
- `$1N243` → `+3V3_FUSED`。

### 1.4 STM32 2×12 排针编号必须复核

若 H1/H2 使用常见的“每列奇偶编号”2×12 封装，即第一列为 1/2、第二列为 3/4，依据模块板上丝印，建议映射如下：

| 功能 | 当前网表 | 建议焊盘 |
|---|---:|---:|
| +5 V | H1.1、H1.2 | H1.1、H1.2，正确 |
| PA9 / USART_TX | H1.3 | **H1.4** |
| PA3 | H1.18 | **H1.17** |
| PA1 | H1.20 | **H1.19** |
| PA2 | H1.19 | **H1.20** |
| PA0 | H1.21 | **H1.22** |
| PA10 / USART_RX | H2.6 | **H2.5** |
| PB5 / RESET_CTL | H2.16 | **H2.15** |
| GND | H1.23/24、H2.23/24 | 正确 |

以上编号必须与实际模块、PCB 封装和载板朝向共同确认。最可靠的方法是：打印 1:1 封装覆盖实物，并使用万用表从模块 MCU 引脚/丝印孔位到向上排针逐点测通。不得只凭原理图符号的左右排列判断孔号。

### 1.5 已检查为合理的网络

- `J12 → PPTC → 磁珠 → 模块电源` 的两路独立供电结构合理；
- C5=10 µF/10 V，C6=47 µF/16 V，C7=10 µF/10 V，C8=100 nF/50 V 的组合合理；
- D7、D8 保护电源，D9～D12 保护四路外部 IO；若实装确为 `PESD…S1BA` 双向型号，则无正反极性问题；
- U3.1/2 与 U4.1/2 分别完成 E220 的 VCC—3.3 V、3.3 V—VIO 短接；
- U6.2=VIO，U6.8=TXD，U6.9=RXD，其余未使用调试/SPI脚可保持 NC；
- U1/U2 的 M1/M0 通过 R20/R19=0 Ω接地，默认普通工作模式；
- 四路 IO 的 `MCU引脚—100 Ω—端子` 及端子侧 TVS 拓扑合理。

## 2. PCB 机械拓扑

### 2.1 结构形式

连接板安装在 STM32 与 E220 两块模块上方，模块向上的排针穿过连接板并在连接板顶面焊接。建议板框为：

1. STM32 区：覆盖 STM32 两组 2×12 排针和连接器/防护器件；
2. E220 区：采用 U 形、梳形或大开窗骨架，只在 1×9 和五组 1×2 排针周围保留 PCB；
3. E220 射频模块、金属屏蔽罩、SMA/同轴连接器、USB 口和按键上方不留 PCB；
4. 各排针小岛必须通过沿模块边缘的窄梁连成单一板体，不能形成互不相连的 PCB 小岛；
5. LoRa 大开窗边缘距射频屏蔽罩外缘至少 3 mm，距 SMA/同轴接头活动包络至少 8 mm；
6. 板框必须依据实物排针中心坐标绘制，不能仅使用模块标称 53×27 mm 或手工估计的 58×28 mm 外形。

LoRa 区建议保留排针条宽度 6～7 mm，连接窄梁宽度不小于 5 mm，内角圆角半径不小于 2 mm。不得使用宽度小于 3 mm 的细颈连接，以免加工和振动后开裂。

### 2.2 模块与连接板固定

- STM32、E220 必须分别固定在绝缘安装板或支柱上，不能由排针和顶置 PCB 承担模块重量；
- 两块模块向上排针的焊接平面高度差控制在 0.3 mm 内；
- 顶置 PCB 安装时不得靠按压使两组排针勉强对孔；
- 建议至少增加两个 M2.5 或 M3 绝缘支柱固定顶置 PCB；若无法增加固定孔，必须在模块本体四角可靠固定后再焊接顶板；
- 排针露出顶置 PCB 的长度建议 1.0～2.0 mm；若扣除 1.6 mm 板厚后没有足够露出量，不采用该直焊结构。

## 3. 嘉立创 PCB 基本制造参数

```text
板层：2层
基材：FR-4，TG150或更高
板厚：1.6 mm
铜厚：1 oz（35 µm）
表面处理：无铅喷锡；若预算允许可选沉金以提高孔焊盘平整度
阻焊：绿色优先，便于检查且成本最低
成品板公差：采用工厂标准，关键配合由孔径和长圆孔吸收
最小线宽/线距：0.25 / 0.25 mm
常规信号线宽：0.30 mm
+3V3_RADIO、+5V_MCU主干：1.0 mm
电源短支路：0.60～0.80 mm
地：底层尽量完整铺铜，顶层空余区域补地并打地过孔
普通过孔：成品孔0.30 mm，焊盘0.60 mm
电源换层过孔：成品孔0.40 mm，焊盘0.80 mm；每个电源至少2孔并联
铜到板边：≥0.50 mm
走线到非金属孔：≥0.50 mm
器件焊盘到板边：≥1.0 mm
排针焊盘中心到板边：≥1.5 mm
板框外角：R2 mm以上
大开窗内角：R2 mm以上，禁止尖角
```

## 4. 向上排针直焊孔参数

适用于常见 0.64 mm 方针，实际仍须用游标卡尺测量：

```text
排针间距：2.54 mm
基准孔：成品孔1.10 mm，焊盘直径1.90～2.00 mm
阻焊开窗：焊盘外扩0.05～0.08 mm
最小环宽：≥0.35 mm
非基准排针组：可使用1.10×1.50 mm金属化长圆孔
长圆孔方向：沿多组排针累计误差最大的方向
Pin 1：使用方形焊盘并在丝印上标三角形
孔类型：全部为金属化通孔，不使用普通非金属孔
```

H1、H2、U1～U6 在 BOM 中设为不安装/DNP。它们代表模块现有向上排针对应的裸金属化孔，不放置排母或线对板连接器实体。

## 5. 元器件面与布局顺序

- 所有 SMD 和螺丝端子放在连接板顶面；连接板底面不放 SMD，防止与模块器件、屏蔽罩或 USB 外壳干涉；
- J12 电源端子、J13/J14 IO 端子放在远离 LoRa SMA 的 MCU 一侧板边；
- 电源链路顺序按 `端子 → PPTC → 磁珠 → 电容/TVS → 模块孔`，器件紧凑排列；
- FB4、C6/C7/C8 到 E220 供电孔的总路径尽量小于 15 mm；C8 距供电孔建议小于 5 mm；
- D9～D12 靠近 J13/J14，TVS 到地的回路短而粗，每两只 TVS 旁至少一个地过孔；
- Q2、R16～R18 靠近 U5；
- UART 串联电阻靠近各自发送端；
- LoRa 骨架区除供电、UART、RESET、M0/M1 必要连接外不布置其他信号。

## 6. 布线与 EMC 参数

1. 顶层优先走所有信号和电源，底层保持连续 GND；必须换层时使用短距离底层跳线，并在换层点附近补地过孔；
2. UART、RESET 与外部 IO 不需要等长；禁止围绕 LoRa 射频模块形成长闭合铜环；
3. E220 屏蔽罩和 SMA 上方的大开窗内，顶层、底层均不得有铜、走线、过孔、丝印或器件；
4. SMA/同轴口周围保留至少 8 mm 机械禁布区，同轴线弯曲半径建议不小于 20 mm；
5. 在 MCU 区每 10～15 mm布一个地缝合过孔，在 LoRa 开窗边缘不做密集闭合地过孔环；
6. UART 与 3.3 V 电源不要长距离紧贴板边并行；UART 下方必须有连续地参考；
7. 给所有排针通孔启用泪滴，避免振动使细线与焊盘连接处开裂；
8. 大电流电源焊盘采用4辐条热焊盘或直接连接，确保手工可焊；普通信号排针可使用热焊盘。

## 7. 出板前强制检查

1. 修正原理图四项问题并重新导出网表；
2. 检查 UART 两个网络的网络度数均为2，`LORA_RESET_N`网络度数为3；
3. 确认 F3/F4 导出封装为1206，不再是R0603；
4. 逐一核对 H1/H2、U1～U6 的 Pin 1 朝向和焊盘号；
5. 1:1打印顶置 PCB，与两个实物模块同时套孔；
6. 检查连接板底面与模块最高器件之间至少有1.0 mm余量；
7. 完成 DRC、未连接网络检查、3D 最大包络检查；
8. 首板只做5片；先装一片进行通断、供电电流、UART、复位、M0/M1、连续发射和振动测试，再装其余板。
