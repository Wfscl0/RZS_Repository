# RES 两端完整接线说明（S017 Si4463 版本）

日期：2026-09-19。适用于本轮 `si4463_final_20260918` 两端固件和 STM32G0B1CBT6 开发板。A5/B2 等开发板丝印分别指 PA5/PB2，不是封装第 5/2 脚。接线按端子名称识别，不按线颜色或照片方向判断。

更新：用户已连接两端 MCU 与 Si4463；已烧录修正版并验证基本双向无线和 ACK。其他外围尚未完成 HIL。本接线表保持有效，软件和实测状态见 [9 月 19 日实机记录](SI4463_LIVE_TEST_20260919.md)。

## 1. 两端相同：S017 无线模块

| MCU/电源端 | S017 针脚号及名称 | 必须注意 |
|---|---|---|
| 稳压 3.3 V | 1 VCC、2 VCC | 两脚都接，不接 5 V |
| 本端 GND | 11 GND、12 GND | 两脚都接 |
| PA4 | 9 nSEL | 低有效片选，建议 10 kΩ 上拉至 3.3 V |
| PA5 | 6 SCLK | SPI1 时钟 |
| PA6 | 7 SDO | 模块输出，MCU MISO |
| PA7 | 8 SDI | 模块输入，MCU MOSI |
| PB2 | 5 nIRQ | 低有效中断输出，软件上拉输入并轮询 |
| PB3 | 10 SDN | 高=关断，低=工作；建议 10 kΩ 上拉至 3.3 V |
| 不接 | 3 GPIO0、4 GPIO1 | 本驱动经 SPI 查询 CTS，无需 GPIO1 连线 |
| 匹配工作频段的天线 | 模块天线接口 | 按实物 ANT/SMA 接口连接 |

PB3/SDN **不是 STM32 的 NRST**。不要把 J-Link RST 接到 SDN。

当前软件在复位/初始化开始时将 SDN 置高，延时后拉低并加载配置。正常初始化完成时 SDN 低；SPI/CTS/芯片/FIFO/发射超时故障时 SDN 高并停止运行许可。旧接线说明中“SDN 默认下拉”的建议已被本版本上拉关断方案替代。

旧 E220 的 VIO/TXD/RXD 接法不再适用。PA9、PA10 不接 S017，也不要接到 S017 的 GPIO0/GPIO1。该模块采用 GFSK，不是 LoRa 调制。

## 2. 两端相同：MCU 供电与 J-Link

每端单独建立本地 GND：MCU、S017、该端电源及其接口电路共地。无线通信不要求用一根地线把遥控端和车载端连起来。

| J-Link 端 | 对应 MCU 端 |
|---|---|
| TMS/SWDIO | PA13 / SWDIO |
| TCK/SWCLK | PA14 / SWCLK |
| RST/nRESET | NRST / RST |
| GND | GND |
| VTref（目标电压参考输入） | MCU 3.3 V 电源轨 |
| TDI、TDO/SWO、RTCK、TRST、RXD、TXD | 本次 SWD 调试不接 |
| 5 V 输出 | 不接 MCU 3.3 V 或 S017 |

若调试器排针只标“3V3”而未标 VTref，应先确认它是参考输入还是供电输出；不能把两个稳压器输出直接并在一起。

MCU 开发板可以按板卡说明使用 USB 供电，或使用外部合适的电源输入。不要把电池 12 V/车上 24 V 接到 MCU 的 5V/3V3 排针。外部供电与 USB 同时连接时，应确认开发板具有供电隔离，避免反向灌电。S017 由能承受发射瞬时电流的 3.3 V 稳压轨供电，不能由 GPIO 或调试器信号脚供电。

## 3. 遥控端：引脚总表

| MCU 端 | 外部连接 | 软件定义 |
|---|---|---|
| PA4～PA7、PB2、PB3 | 第 1 节 S017 | 无线 SPI 与控制 |
| PB0 | GO 按钮/检测继电器的干接点输出 | 高=未按，低=按下；25 ms 防抖 |
| PB1 | STOP 常闭失效安全检测链输出 | 低=健康，高=急停/断线/检测链掉电 |
| PB6 | INA226 SCL | I²C1 时钟，3.3 V 上拉 |
| PB7 | INA226 SDA | I²C1 数据，3.3 V 上拉 |
| PA8 | INA226 ALERT，可暂不接 | 预留输入，当前故障判定来自 I²C 轮询 |
| PB10 | 四路灯继电器 IN4 | 蓝灯，低电平亮 |
| PB11 | 四路灯继电器 IN3 | 黄灯，低电平亮 |
| PB12 | 四路灯继电器 IN2 | 绿灯，低电平亮 |
| PB13 | 四路灯继电器 IN1 | 红灯，低电平亮 |
| PA13、PA14、NRST | 本端 J-Link | SWD 调试 |
| PA9、PA10 | 不接无线模块 | 当前保留的旧 UART 外设 |

本表采用用户已确认的灯继电器颜色编号：**1 红、2 绿、3 黄、4 蓝**。因此 PB10 并不是接 IN1，而是接 IN4。PB6/PB7 已用于 INA226，不能并接为无线 SPI。

### 3.1 直接连接按钮干接点

GO 按钮：`PB0 → 按钮 NO`，`按钮 COM → GND`。未按下开路，由 MCU 上拉为高；按下接地为低。

急停按钮：`PB1 → 急停 NC`，`急停 COM → GND`。急停机械释放时 NC 导通，PB1=低；按下后断开，PB1=高。检测线断开同样为高。不要把 PB1 永久短接 GND 来模拟健康，否则急停失去作用。

### 3.2 保留原 Relay_ButtonCheck 两路低触发模块时

下面接法替代上面的按钮直连接法；不要把两种方案并联。只有模块已验证“IN 接地吸合、IN 开路释放”时采用。

| 检测模块端子 | 接线 |
|---|---|
| VCC | 符合模块标称电压的 5 V（按实物确认） |
| GND | 遥控端 GND |
| IN1 | GO 按钮 NO；该按钮 COM 接 GND |
| COM1 | MCU PB0 |
| NO1 | 遥控端 GND |
| NC1 | 不接 |
| IN2 | 急停按钮 NC；该按钮 COM 接 GND |
| COM2 | MCU PB1 |
| NO2 | 遥控端 GND |
| NC2 | 不接 |

健康时急停 NC 导通，检测继电器 2 持续吸合，NO2 把 PB1 拉低；按下急停、检测模块断电或按钮线断开后，继电器 2 释放，PB1 上拉为高。模块输入端应有合适的上拉，使按钮断开不会悬空误吸合。PB0/PB1 仅接无源触点，不接检测模块的 5 V IN 控制网。

验收：健康 PB1≈0 V，急停按下/拔掉检测板电源/断开一根检测线时 PB1≈3.3 V。GO 未按 PB0≈3.3 V，按下≈0 V。

### 3.3 四路外灯继电器

| 模块端子 | 接线 |
|---|---|
| IN1 / IN2 / IN3 / IN4 | PB13 / PB12 / PB11 / PB10 |
| GND | 遥控端 GND |
| VCC/JD-VCC | 按该继电器板电路供电；线圈为 5 V 型，不能由 MCU 3.3 V 引脚承担四个线圈的电流 |
| 第 n 路 NO | 对应指示灯允许的电源正极 |
| 第 n 路 COM | 对应灯正极 |
| 第 n 路 NC | 不接 |
| 各灯负极 | 灯电源 GND |

COM 与 NO 在纯干接点开关中可以交换，但必须使用 NO，不能用 NC。裸 LED 必须串限流电阻；有内置限流的 5 V 成品指示灯按其铭牌供电。

“5 V 线圈”不能证明输入能兼容 3.3 V。上述 MCU→IN 接法要求模块在 0 V 可靠吸合、3.3 V 可靠释放且不向 MCU 回灌 5 V。若不满足，需使用能保持低有效逻辑的接口电路。不要只因低电平能吸合就认为高电平释放也正常。

正常运行预期蓝、绿常亮，红、黄熄灭；低电量或故障按软件状态常亮提示。上电仍有约 1 s 四灯自检。自检不是无线已联通的证据。

### 3.4 INA226 与电池

| INA226 端子 | 接线 |
|---|---|
| VCC | 遥控端 3.3 V |
| GND | 遥控端 GND/电池负极 |
| SCL | PB6 |
| SDA | PB7 |
| ALERT | PA8，可选 |
| 地址选择 | 7 位地址 0x40；按模块跳线表配置 |

SCL/SDA 上拉至 3.3 V，不能上拉到 5 V。带板载 R010 分流器的电流测量模块：电池正极经保险/开关接其分流器上游大电流端，分流器下游大电流端接遥控端电源转换模块输入；电池负极接本端 GND。**芯片的 IN+/IN− 检测脚本身不是负载供电端**；只有确认板载分流器和大电流端子后才串入电源路径，不能拿细采样排针承载整机电流。

软件标定为 10 mΩ（R010）分流器，电池阈值按当前 3S 方案：11.1 V 预警、10.5 V 严重低电量。模块/分流器/电池规格不同时必须同步改标定。缺少 INA226 或测量无效会进入 STOP，不能在仅接 MCU+无线模块时期待完整 READY 状态机通过。

## 4. 车载端：引脚总表

| MCU 端 | 外部连接 | 软件定义 |
|---|---|---|
| PA4～PA7、PB2、PB3 | 第 1 节 S017 | 无线 SPI 与控制 |
| PB10 | 双路安全继电器模块 IN1 | 低=R1 吸合，高=释放 |
| PB11 | 双路安全继电器模块 IN2 | 低=R2 吸合，高=释放 |
| PB12 | START_OUT 接收接口（可选） | 3.3 V 高有效，约 100 ms GO 脉冲 |
| PB13 | FAULT_OUT 接收接口（可选） | 3.3 V 高=故障；不是 VCU 的 RES_ERROR 硬线 |
| PB8 | CAN 收发器 RXD | FDCAN1_RX，收发器输出到 MCU |
| PB9 | CAN 收发器 TXD | FDCAN1_TX，MCU 输出到收发器 |
| PA0 | CAN 收发器 STB | 高=待机，低=正常；须与实际型号一致 |
| PA13、PA14、NRST | 本端 J-Link | SWD 调试 |
| PA9、PA10 | 不接无线模块 | 旧 UART 保留 |

START_OUT/FAULT_OUT 都是 MCU 逻辑输出，禁止直接接 12 V/24 V 回路或直接驱动线圈。不使用时悬空。若 GO 已由 CAN 传输，VCU 不应把 CAN GO 和 START_OUT 当成两次独立启动。

### 4.1 车载继电器控制侧

模块 VCC/JD-VCC 按实物供电（已有照片中 5 V 线圈型使用合适的 5 V 线圈电源）；模块 GND 接本端 GND；IN1 接 PB10，IN2 接 PB11，前提同第 3.3 节的 3.3 V 输入兼容要求。MCU 侧两路可加 4.7–10 kΩ 上拉至 3.3 V，实际还必须验证 MCU 掉电时不会被模块回灌。

初始化/复位或无线初始化失败：R1、R2 均释放。无线模块正常且车载端独立待机：R1 吸合、R2 释放。完整建链并通过 READY×3：两路吸合。STOP、超时、驱动故障或 CAN 故障：两路释放。最新候选逻辑支持拔起急停、只重启遥控端后重新确认 READY 恢复许可，但不能清除仍存在的本地故障或整车外部锁存；此候选尚未烧录，见 [恢复逻辑说明](REMOTE_RESTART_RECOVERY_20260919.md)。

### 4.2 车载继电器触点侧：必须区别两份历史资料

当前存在两种不同的历史拓扑，不能混接：

| 资料 | R1 触点 | R2 触点 |
|---|---|---|
| 先前用户 RES 接口图 | 24 V 供电 OUT → NO1—COM1 → EBS_PWR_IN | SDC_IN → NO2—COM2 → SDC_OUT |
| 2026-09-15 ASF 文字 | 两个 NO 触点串联在 SDC 中 | SDC_IN → COM1—NO1 → COM2—NO2 → SDC_OUT |

两者的 R1 含义不同。软件 PB10/PB11 仅定义继电器命令，不能判断实物究竟采用哪一种。接线前必须以最终整车安全原理图确认 R1 是 EBS 供电开关还是 SDC 串联开关，并同步修订 ASF；**不要把 24 V 电源直接接到用于无源 SDC 触点的任意端子，更不能把它接 MCU 引脚**。

本轮初次 HIL 只连接控制侧，触点侧使用断电通断表或独立低压假负载验证，真实车辆回路接法待上述图纸冲突解决后执行。NC 触点均不作为本版本健康吸合的许可输出。

### 4.3 CAN 收发器与 VCU

| 收发器端 | 接线 |
|---|---|
| TXD | MCU PB9 |
| RXD | MCU PB8 |
| STB（若有且高待机） | MCU PA0 |
| VIO（若有） | 3.3 V |
| VCC | 按收发器型号，例如 TCAN1042HGV-Q1 主电源为 5 V；不能对所有模块一概套用 |
| GND | 车载端本地 GND |
| CANH | VCU CANB_H |
| CANL | VCU CANB_L |
| 总线参考地 | 按整车 CAN 线束方案连接 |

MCU 的 PB8/PB9 不能直接接 CANH/CANL，必须经过收发器。若模块无 VIO，先确认 RXD 输出电压与 MCU 兼容；若只有 EN 而无 STB，应按该型号真值表调整，不能照 PA0 高待机假设接。

总线设置 500 kbit/s、Classic CAN 标准帧。仅总线两个物理末端放 120 Ω 终端，整车已装终端时不要再增加第三个。断电测 CANH–CANL 通常约 60 Ω（两个 120 Ω 并联）。单独 HIL 使用正确配置的 USB-CAN/另一 CAN 节点提供 ACK；仅一个监听模式分析仪不能提供 ACK。当前软件把 CAN bus-off/发送失败视为安全故障，因此仅接两套无线而不接可用 CAN 节点无法完成车载正常运行验收。

车载发送 0x510 状态、0x511 GO、0x512 诊断。VCU 的 150 ms 状态监督及 RES_ERROR→非可编程故障锁存属于另外的实物安全链路，不能把 PB13 直接等同或替代它。

2026-10-04 上电接线修订：TSMS 上电前先给 `RES_ERROR` 12 V 健康电平，故障时为 0 V；删除 EBS/RES 两路都输出 1 才开始监测的上电等待设计。EBS 的安全回路经 DCDC 降为 12 V 后接 `SDC_IN`；EBS_PWR 仍为 24 V 主电源，不能与 12 V 安全回路混接。两份历史触点拓扑的差异仍需最终整车图纸确认，不能由本次电压说明推断已解决。

## 5. 一次接好后的检查顺序

1. 断电对照 S017 针脚号检查六根信号和四个供电脚；重点检查 SDO/SDI 没有反接、VCC 没有接 5 V、SDN 没有误接 NRST。
2. 分别给两端合适电源，测 S017 VCC≈3.3 V；保持真实车辆回路与首次 HIL 隔离。
3. 接两只 J-Link，核对每端 `res_si4463_diag.part=0x4463`、`ready=1`、`error=0`。未接模块时 ready=0 是预期，不应旁路此故障。
4. 遥控端接有效 INA226、GO/STOP 检测链；STOP 健康时 PB1 低、GO 未按时 PB0 高。车载接可 ACK 的 500 kbit/s CAN 节点。
5. 确认两端 `tx_done`、`rx_packets` 递增，遥控 `accepted_acks` 递增；再观察 READY×3 后 R1/R2 接点闭合及蓝绿常亮。
6. 按 GO：START_OUT 约 100 ms，GO 计数只增加一次，长按不重复。按 STOP：两继电器释放，停止正常心跳。最新候选要求拔起急停并重启遥控端、重新建链和 READY 确认后恢复许可，不自动 GO；板上旧版行为不同，以烧录映像为准。
7. 分别验证遥控掉电、无线断链、CAN 断开、车载 NRST、INA226 断开。实测故障到接点断开的时间，并把结果记录进 HIL。软件回归不能替代该测量。
