# VCU FSEC初步安全优化记录（2026-07-29）

## 1. 依据与边界

- 物理连接以 `全车原理图/RZS_TestBench/电气拓扑.NET` 为准。
- AIN4连接储气侧气压传感器，模型中作为 `airprs_sensor1 / airprs_ready`。
- AIN5连接电磁阀下游、气缸侧气压传感器，模型中作为 `airprs_sensor2 / ebs_working`。
- HO1、PA30、HIN1分别连接 `EBS_Trig`、`EBS_WatchDog`、`EBS_Check`。
- 四轮制动油压继续来自CAN1的 `ESP_T_03`，没有改为本地ADC。
- 外部故障锁存电路仍是安全回路的主要硬件保护；本次增加的软件锁存属于冗余保护。
- 根层模型接口保持19个输入、12个输出，名称、方向和顺序均未改变。

## 2. 已实施的模型优化

### 2.1 制动传感器断路/短路

- 使用制动踏板ADC原始电压进行电气有效性判断。
- 当前宽范围阈值为 `0.10 V～4.90 V`，用于标定完成前降低误触发概率。
- 电压越界时立即撤销 `brake_sensor_valid`，因此R2D许可在下一次10 ms模型运算时失效。
- 越界持续100 ms后确认故障并点亮EBS故障灯；连续500 ms恢复正常后清除故障。
- `brake_on`仍由ESP四轮实际油压共同判断，但增加了制动传感器有效性门控。这样断开制动传感器后，即使ESP油压残留，也不能进入R2D。

### 2.2 ESP、RES与EBS_Driver有效性

- `ESP_T_03`生命信号、RES通信校验、EBS_Driver反馈任一异常持续300 ms后置安全故障。
- 连续500 ms恢复正常后才清除该故障。
- 安全故障在AS Ready、AS Driving或状态过渡过程中进入AS Emergency。

### 2.3 两路气压与EBS动作响应

- 修正 `ebs_working`的数据源：现在使用电磁阀下游的气缸侧气压传感器2，而不是储气侧传感器1。
- 储气压力低于2.5 bar持续500 ms时判定“储气不足或储气侧传感器异常”。
- 下游压力高于储气压力1.5 bar以上持续200 ms时判定两路信号不合理。
- 当EBS触发且储气压力不低于2.5 bar时，下游压力必须在500 ms内升至1.0 bar以上，否则锁存EBS响应故障。
- EBS响应故障仅在ASMS关闭、EBS_Driver正常、储气有效且下游已泄压的条件连续满足1 s后允许恢复。
- 0～10 V传感器的0 V和10 V本身是合法量程端点，因此软件不能只根据端点区分真实零压/满压与对地/对电源短路。最终仍需结合输入电路上拉/下拉设计和实车故障注入确认。

### 2.4 Emergency、TS与电机转矩

- AS Emergency进入时置 `safety_lock=1`；该锁存在模型重新初始化前不清除，即要求VCU低压断电重启。
- AS进入Emergency时，`as_emergency_flag`在同一模型步直接强制TS输出为0；随后由`safety_lock`保持禁止状态，阻止再次进入手动或自主行驶。
- ASMS关闭、RES Stop或综合安全故障均可使AS Ready/Driving进入Emergency。
- 自主转矩许可修改为：`ASMS && AS_Driving && R2D完成 && 未锁存故障`。
- R2D回零过程、AS Ready、AS Finished和AS Emergency均不能输出自主转矩。
- 从综合故障确认到Stateflow接收增加一个10 ms Unit Delay，用于打断原有函数调用子系统之间的同周期数据依赖环。

## 3. 当前阈值

| 项目 | 确认时间 | 恢复时间 | 当前阈值 |
|---|---:|---:|---|
| 制动ADC越界 | R2D许可立即撤销；故障100 ms | 500 ms | 0.10～4.90 V |
| ESP/RES/EBS_Driver失效 | 300 ms | 500 ms | 布尔/生命信号有效 |
| 储气不足或传感器异常 | 500 ms | 500 ms | 储气压力低于2.5 bar |
| 两路气压不合理 | 200 ms | 见EBS恢复条件 | 下游高于储气1.5 bar |
| EBS动作无压力响应 | 500 ms | ASMS关闭后有效条件1 s | 下游未达到1.0 bar |

以上均为初步台架值。ADC传感器完成实车标定后，应重新调整电气边界、压力门槛和恢复滞回。

## 5. 上车前仍需验证

1. 实测制动踏板传感器正常零点、满量程、电源短路、对地短路和开路时ADC电压。
2. 分别断开ESP_T_03、RES和EBS_Check，确认300 ms后进入Emergency、TS关闭且ASSI/蜂鸣器状态正确。
3. 断开气缸侧气压传感器后触发EBS，确认500 ms响应故障能够置位。
4. 验证EBS触发后的实际建压时间；若机械系统正常建压超过500 ms，应适当增加阈值。
5. 断开ASMS和触发外部锁存电路，确认硬件安全回路先动作，软件随后锁存，低压不断电不能重新激活TS。
6. 高压断开或架空驱动轮条件下，验证R2D前、转向回零期间和Emergency状态电机命令转矩始终为0。
