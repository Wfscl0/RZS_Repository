# RES 状态机与 ASF 失效模式审计（2026-09-14）

## 目标动作

本轮按用户指定的时序验证：

1. 仅车载端上电：状态 `WAIT_LINK`，继电器 1 闭合、继电器 2 释放，`FAULT_OUT` 有效；
2. 遥控端上电并建立新鉴权会话：连续 3 帧有效 READY 后，两个继电器闭合；
3. 新 GO：两个继电器保持闭合，`START_OUT` 产生 100 ms 脉冲，并只产生一个 CAN GO 事件；
4. 遥控 STOP、无线心跳停止或车载复位：两个继电器释放并进入锁存故障。

## 遥控端与新版 ASF 心跳规则

- 上电约 1 s 四灯自检，不产生 READY 运行许可；
- 健康且已获得车载有效 ACK 后才允许 GO；
- 正常运行心跳周期 200 ms；
- STOP 锁存后只发送安全 STOP，不再发送普通 HELLO/HEARTBEAT 或 GO；
- STOP 不刷新车载运行许可计时器；车载端仍独立执行 500 ms 有效报文超时；
- 急停释放不能自动解除遥控端 STOP 锁存；需新遥控会话；
- 车载外部非可编程安全锁存不能由无线恢复或 VCU 软件复位。

现有 `ctest` 8/8 通过，覆盖协议、UART 恢复、遥控状态机、车载状态机、四灯状态、双端联动、INA226 诊断和 STOP 台架配置。

## 重要冲突与限制

仓库内 `ASF_UART_REPAIR_20260912.md` 曾记录“未建链两继电器均释放”，而 `HIL_TEST_CHECKLIST_CN.md` 的 CAN-05/A 节及本轮用户要求明确“车载单独上电 R1 闭合、R2 释放”。当前代码已按后者恢复。正式提交 ASF 前必须由车队确认采用哪一条规则；若最终规则要求两继电器均释放，应将 `apply_outputs(app, true, false, true)` 改回全释放并同步修改测试。

即使本轮主机测试全部通过，也不能据此声明赛事合规。继电器触点、低电平有效性、复位/掉电释放、500 ms 实际时延、VCU 150 ms 监督、非可编程锁存、合法频点和整车 HIL 仍须单独取证。
